# 第一代实际架构

数据流：两个数字分别编码 → 两层局域多 mode 主辅模块 → 查询位置读出59个答案得分。

## 输入与输出

任务为模59加法，共3481道题。训练集870题，测试集2611题，数据划分种子为0。
序列长16。两个数字放在位置0和7。查询位置为15。
数字用可学习Embedding编码。角色Embedding与位置参数相加。主状态维度64。
最后仅对查询位置做LayerNorm，再用Linear(64,59)读出。

## 每层计算

设主状态为h_i，mode为m。
源映射产生8维源s_{i,m}=D_m h_i+d_m。
每个mode左右两路各有8维辅助状态。每层开始时两路均为零。

一次局域传播只读取r格以内的源和r格外的上一轮辅助状态。
在T轮传播期间，主状态和源保持不变。
完成全部传播后，辅助状态严格等于有限范围指数和：

\[
a^{+}_{i,m}=\sum_{q=1}^{rT}\lambda_m^q s_{i-q,m},\qquad
a^{-}_{i,m}=\sum_{q=1}^{rT}\lambda_m^q s_{i+q,m}.
\]

序列外的源取零。左右两路拼接成16维a_{i,m}。
随后计算每个mode的实际写回：

\[
u_{i,m}=\beta g_m W_{out}[(V_mh_i)\odot(A_m a_{i,m})],\quad
g=\operatorname{softmax}(\mathrm{mode\_logits}).
\]

主状态每层只更新一次：

\[
h'_i=\operatorname{LayerNorm}(h_i+\sum_m u_{i,m}+b_{out}).
\]

两层共更新两次。两层的可学习映射分别设置。传播器及固定衰减系数共享。
没有内容注意力，没有MLP/FFN，没有全局池化。

## 参数

| 量 | 状态与含义 |
|---|---|
| β / `local_coupling` | 每条运行固定；乘在mode写回上；不是logits温度倒数 |
| λ_m | 固定不训练；名义长度ξ_m满足λ_m=exp(−1/ξ_m) |
| ξ_m | M≥2时在0.7至32上对数等间距；M=1使用32 |
| g_m | 可训练的mode权重，softmax归一化 |
| 源映射、主辅投影、输出矩阵 | 参与训练 |
| Embedding、位置、LayerNorm、分类器 | 参与训练 |

M=4时，可训练参数62787个。另有4个不训练的衰减参数，共62791个参数元素。
写回矩阵是普通可学习矩阵，没有固定范数约束。
因此β是训练实验的控制设置，不等于独立、不可补偿的有效耦合。

## 两批实验

架构扫描：β=1、wd=0.1，r×T×M为64个组合，各3seed。
耦合强度×权重衰减扫描：固定r=3、T=4、M=4、两层。
其β有5档，wd有7档：0.01、0.03、sqrt(0.003)、0.1、0.3、sqrt(0.3)、1。
精确数值以逐运行config.json为准。

两批均为硬标签交叉熵，全批量AdamW，lr=0.001，betas=(0.9,0.98)，eps=1e−8，梯度裁剪1。
前100步warmup，之后学习率保持常数。
bias与LayerNorm不加weight decay；固定λ不训练。
两批每500步保存评价记录。架构扫描每1000步存检查点，β×wd扫描每500步存检查点。

## 理论联系

固定源条件下，局域递推与截断的指数长程求和严格相等。
这说明跨位置通信怎样实现，不能直接推出整个可学习主状态更新遵循某个能量下降定律。
本包没有把这一恒等式扩展成与一般内容注意力或完整Transformer的等价证明。
